# AssetNote Web 产品背景

<!-- impeccable:product-schema 1 -->

## Platform

web

## 适用范围

本文记录 `apps/web` 浏览器应用的产品背景。产品定位与首版范围已由项目所有者确认；实现状态以当前代码和架构文档为依据。移动端不在本次初始化范围内。

系统边界与依赖方向以[架构总览](../../docs/architecture/overview.md)为准，本文不改变其约束。

## 用户

主要用户是项目所有者本人，以及具有相同需求的个人股票投资者。核心任务是记录自己的持仓、管理个人钱包记录和查看行情。

使用场景以个人资产管理为中心。邀请制控制账户准入，不代表存在共享钱包、团队协作或代客管理需求。

## 产品目的与定位

AssetNote 是个人持仓记录与行情查看工具。用户可以维护自己的资产记录，并结合行情了解持仓状况。

产品不参与证券交易。个人钱包用于记录资产与持仓，不承担下单、撮合或实际资金划转功能；录入数据不会触发真实交易。

首版成功的标准是让个人用户能够完成手工记录与查阅持仓、查看行情的核心流程。相较其他工具的独特机制、量化指标和商业定位尚未确定，不作额外宣传承诺。

## 使用流程与环境

- 通过浏览器使用 Web 应用。
- 采用邀请制准入；公开注册不在当前范围内。
- 首版手动录入个人钱包与持仓相关数据，再查阅自己的记录和行情。
- OCR 与模板导入属于后续计划，不作为首版已具备的能力。
- 邀请、登录、录入、查阅等流程的具体页面组织在后续设计任务中确定。

## 能力与约束

### 已确认的首版范围

- 行情查看。
- 个人钱包与持仓记录。
- 个人使用，数据暂由用户手动录入。
- 邀请制账户准入，保留现有三种平台角色：`SUPER_ADMIN`（超级管理员）、`ADMIN`（管理员）、`USER`（用户）。
- 不执行真实交易，不提供实时交易功能。

### 后续计划

- OCR 识别录入。
- 模板导入。

这些计划尚未确定输入格式、识别范围、模板规范和交付时间。

### 当前实现状态

- Web 已接入邮箱密码登录、当前会话查询和退出，包含中文登录页及最小账户确认页；行情、钱包与持仓业务界面尚未实现。
- API 已实现面向浏览器的邮箱密码认证、服务端会话及上述平台角色；Web 通过共享运行时契约和集中 HTTP 客户端消费接口。
- 邀请制是已确认的产品与架构约束，邀请发送与接受流程尚未实现。首个超级管理员通过受控引导操作创建。
- 行情集成已在架构中接受，但 `market-data` 功能和计划采用的 `stock-sdk` 适配器尚未实现。

### 必须遵守的边界

- Web 负责呈现与交互，通过显式 HTTP 边界访问 API；业务规则、权限与持久化数据由 API 管理。
- 行情供应商接入归 API 所有，Web 不直接调用上游行情服务，不依赖 `stock-sdk`。
- 展示行情时明确来源与时效，不把延迟数据描述为交易所级实时行情。
- 平台角色与个人资产的资源权限是不同的概念，不凭角色名称推导查看或编辑他人钱包的权限。具体规则遵循[认证与会话决策](../../docs/architecture/decisions/0002-email-password-authentication-and-server-sessions.md)。
- 后续共享 HTTP 契约遵循架构约定；当前不为产品背景初始化创建新工作区或接口。

### 待定事项

- 首批支持的市场与资产类型，例如 A 股、港股、美股及是否包含基金。
- 个人钱包的数据结构、账户与币种范围，以及成本、估值和收益计算口径。
- 行情字段、刷新频率、延迟说明和异常状态下的产品行为。“不参与交易”不等于已确定行情刷新方式。
- 是否需要买卖、分红、入金和出金等历史记录；已有移动端占位文案不构成 Web 首版需求。
- 多语言范围、主要浏览器与屏幕尺寸；当前登录和账户界面采用中文。
- OCR 与模板导入的具体范围。

## 品牌与内容事实

产品名称为 AssetNote。尚未确认独立的 Web 品牌素材、固定文案语气或其他品牌承诺。

本文和当前登录、账户界面使用中文。其他产品界面的语言与多语言范围仍待确定。

- 尚未提供真实钱包样例、持仓数据、用户评价或效果指标；后续演示数据应明确标注，不把示例当作真实资产或用户证明。

## 产品原则

1. 围绕个人投资者的查看与记录任务取舍功能。
2. 始终区分资产记录和真实交易，确保记录操作不会被理解为交易执行。
3. 先完成可靠的手工录入与查阅流程，再扩展 OCR 和模板导入。
4. 如实表达数据来源、时效与实现状态，不用计划或示例替代事实。
5. 邀请制与角色服务于账户和权限管理，不自动扩大为多人协作或他人资产管理。
